Third-Party Licenses

BMP Terbuka release builds currently bundle:

  • Tesseract.js 6.0.1 — Apache-2.0
  • tesseract.js-core 6.0.0 — Apache-2.0
  • pdf-lib 1.17.1 — MIT
  • Indonesian traineddata from tesseract-ocr/tessdata_fast — Apache-2.0

The release builder verifies pinned assets and includes third-party license files in the built package where available.

No live AdsOnBread production SDK is bundled in the current source stage. The repository test fixture is not vendor production code.

BMP Terbuka's published source is GPL-3.0; third-party components retain their own licenses.
