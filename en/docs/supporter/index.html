BMP Supporter Pass

Supporter Pass is an optional digital contribution that helps support BMP Terbuka development and operations.

BMP Terbuka's core features remain free. You do not need Supporter Pass to use the extension's core functionality.

Supporter Packages

Current packages:

  • 2 Stars — 1 day
  • 50 Stars — 30 days

Payment uses Telegram Stars.

Both packages are one-time purchases, not automatically renewing subscriptions.

How Supporter Time Is Calculated

If Supporter is not active, the new Supporter period starts from the successful payment time.

If Supporter is already active, the new period is added after the currently active period.

Buying another package while Supporter is still active therefore does not discard the remaining Supporter time.

Supporter Benefits

Current active-Supporter benefits include:

  • bot DM access;
  • unlimited AI support;
  • priority support;
  • longer troubleshooting context;
  • BMP Supporter group tag when Telegram permissions allow it;
  • optional Supporter Wall visibility;
  • activation-period target bonus.

Bot DM + Unlimited AI

While Supporter is active, bot DM and AI support do not use the regular daily AI quota.

AI/Telegram services can still experience temporary outages or technical limitations.

Unlimited access does not permit spam, abuse, or security violations.

Priority Support

Priority support means Supporter reports can be prioritized in the support workflow.

It is not a guaranteed resolution time and does not change the technical limits of third-party services.

Longer Troubleshooting Context

The current bot configuration gives Supporters troubleshooting context up to 6 turns / 6 hours.

This helps with follow-up questions but is not permanent history storage.

BMP Supporter Tag

The bot may try to apply a BMP Supporter tag in the group when:

  • the user is the matching member;
  • Telegram permissions allow the change;
  • no group/tag condition prevents it.

The tag is not permanent and may disappear when Supporter entitlement ends or when Telegram does not allow the change.

Supporter Wall

Supporters can choose:

  • Public
  • Anonymous
  • Private

Public may show the Telegram identity selected for the wall.

Anonymous shows the supporter without public identity.

Private means the supporter is not displayed on the Supporter Wall.

Extension Activation Bonus

Each Supporter payment adds a target extension activation bonus of +14 days.

The target activation period is capped at 60 days.

This bonus affects extension activation entitlement; it does not add extra days to the Supporter package itself.

When the Bonus Appears in the Extension

BMP Terbuka v1.2.0 includes token/refresh behavior for eligible entitlement synchronization.

A token already stored on the device does not necessarily change at the exact moment payment succeeds.

The bonus is applied when entitlement refresh or the next activation-token issuance succeeds.

If the extension asks for re-verification, follow the popup flow. Reinstalling is not required just to receive an updated entitlement.

How to Buy

  1. open the BMP Terbuka bot in DM;
  2. open the Supporter menu;
  3. choose a package;
  4. read the Terms;
  5. choose the agreement/payment button;
  6. complete the Telegram Stars invoice.

The bot processes a successful payment and activates the entitlement.

Payment Succeeded but Supporter Is Not Active

Do not pay again.

Use the payment-support path:

/paysupport

Include a short description of the transaction problem.

Do not send passwords, OTPs, tokens, cookies, card data, or other credentials.

Duplicate Payment / Already Processed Transaction

The payment system uses transaction identity to prevent the same successful payment from being applied repeatedly.

If the bot says the transaction was already processed but the status looks wrong, use /paysupport instead of creating a new payment.

Refunds or Transaction Problems

Use /paysupport for Supporter Pass transaction/refund issues.

Telegram Support/Bot Support is not the party handling BMP Terbuka Supporter Pass purchases.

Refund availability or outcome can depend on transaction status and the applicable rules.

Abuse and Restrictions

Supporter Pass does not permit:

  • spam;
  • abuse;
  • security bypass;
  • bot misuse;
  • credential sharing;
  • behavior that violates community or service rules.

Access can still be limited when necessary for security or abuse prevention.

Supporter Pass Terms

Current terms summary:

  1. Supporter Pass is optional digital support; core features remain free.
  2. Current packages are 2 Stars / 1 day and 50 Stars / 30 days.
  3. Both are one-time purchases, not automatic subscriptions.
  4. Supporter time is added after remaining active time, or from payment time when previously inactive.
  5. Each payment adds a +14-day target activation bonus, capped at 60 days.
  6. Benefits include bot DM + unlimited AI, priority support, longer troubleshooting context, group tag when supported, and optional Supporter Wall visibility.
  7. AI/Telegram services can have temporary outages and abuse can still be restricted.
  8. Transaction/refund issues use /paysupport.

By pressing I agree & pay, the user confirms they have read and accepted the Supporter Pass terms shown by the bot for that transaction.

Privacy

Supporter Pass does not change the principle that BMP content, OCR text, and generated PDFs are not sent to the BMP Terbuka backend as part of the OCR/PDF flow.

Durable data required for bot, activation, Supporter, payment/idempotency, and entitlement functions may be stored as described in the Privacy Policy.

See the Privacy page for full details.
