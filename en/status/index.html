BMP Terbuka Status & Version

This page is the reference for the stable version, installation paths, and distribution status of BMP Terbuka.

Current Stable Version

BMP Terbuka v1.3.0

Public release: 3 October 2026

GitHub Release:

https://github.com/mentaliss/bukabmp/releases/tag/v1.3.0

Download/update page:

https://mentaliss.github.io/bukabmp/en/download/

Google Chrome — Desktop

v1.3.0 is available through the manual GitHub Release package.

Use:

BMP-Terbuka-v1.3.0-github.zip

Chrome Web Store is not publicly available yet (Coming soon). The current stable product is BMP Terbuka v1.3.0; the latest manual package is build 1.3.0.

Microsoft Edge — Desktop & Android

The official path remains Microsoft Edge Add-ons:

https://microsoftedge.microsoft.com/addons/detail/mkgmigiagipmfdlppehhmckfokmpnmlm

BMP Terbuka v1.2.0 is now live on Microsoft Edge Add-ons for Desktop and Android.

Use the official Store listing for installation/update. Do not use diagnostic/audit CRX files as a Store replacement.

Edge Canary is fallback/testing only. Chrome Android is not an official installation target.

Firefox

Not officially supported.

Supported Reader

The current public adapter targets:

https://pustaka.ut.ac.id/reader/

Compatibility does not imply affiliation, endorsement, or official support from the service owner.

Activation & Minimum Version

Expired activation does not require reinstalling the extension.

Minimum-version policy comes from runtime policy. Follow the extension notice and an actually available update path rather than inferring it from this page.

Older Tutorial Videos

Existing videos are still labeled v1.0.4 and remain references for the older flow. Use the v1.3.0 website documentation for current behavior.
