Download BMP Terbuka

This is the canonical BMP Terbuka download and update page.

Google Chrome — Desktop

Latest version: v1.3.0

GitHub ZIP - current stable v1.3.0

Use the official asset:

BMP-Terbuka-v1.3.0-github.zip

Do not use GitHub's automatically generated Source code (zip) or Source code (tar.gz) as the extension package.

For a manual Chrome update, download and extract the new package, then replace/overwrite the contents of the same folder previously selected with Load unpacked. Only after the new files are in that same folder should you open chrome://extensions and press Reload. Reload does not download an update by itself. Do not uninstall, Remove, switch to a different folder, or clear local storage just to perform a normal update.

See Installation & Updates.

Chrome Web Store

Chrome Web Store is not publicly available yet (Coming soon). When it becomes available, Store installations will use normal automatic desktop extension updates. Store updates may be delayed; desktop users can open the Extensions page and use Update when available. Developer mode may need to be enabled temporarily for that action to appear.

Microsoft Edge — Desktop

The official path remains Microsoft Edge Add-ons.

Microsoft Edge Add-ons

Microsoft Edge Add-ons still serves v1.2.0. The GitHub package above is already v1.3.0; the Store listing will follow. Edge Desktop installs and updates through the normal Store mechanism.

Store updates are normally automatic, but they are not always delivered immediately after a new package is published. To check sooner on desktop, open edge://extensions and use Update when available. Developer mode may need to be enabled temporarily. Do not uninstall/reinstall or clear local extension data for a normal Store update.

Microsoft Edge — Android

Use Microsoft Edge Stable + Microsoft Edge Add-ons.

Microsoft Edge Add-ons

Edge Canary is fallback/testing only.

For Edge Android updates, the safest path is to wait for the automatic Store update. Delivery can be delayed, and Edge Android does not provide the same convenient desktop-style Update button.

If you choose to reinstall to get the newest build immediately, create a BMP Terbuka Backup first if you want to preserve extension-local data. Removing/reinstalling the extension can erase local cache/resume/Quiz-source data. PDF files already saved in Downloads/device storage remain safe because they are outside extension storage. After reinstalling, activate again if needed and Restore the backup; Restore remains MERGE.

In v1.3.0, Android Restore uses a dedicated BMP Terbuka restore tab. See Installation & Updates and PDF, Backup, Restore & Storage.

Microsoft Edge v1.2.0

v1.2.0 is live through the official Microsoft Edge Add-ons listing for Desktop and Android. Use the official Store listing; do not install diagnostic/audit CRX packages as a shortcut.
