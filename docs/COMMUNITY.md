# Community

## Buka BMP
Channel resmi untuk:
- release baru;
- status kompatibilitas;
- security notice;
- panduan penggunaan.

## Group Terbuka
Tempat untuk:
- troubleshooting;
- feedback;
- diskusi fitur;
- kontribusi komunitas.

## Aturan utama
Jangan membagikan:
- password/NIM;
- cookie/session token;
- akun;
- materi/PDF yang tidak boleh Anda distribusikan.

Jangan menawarkan:
- penghapusan watermark;
- bypass/stealth terhadap blokir;
- jual-beli credential.

Community gate bertujuan membangun jalur komunikasi dengan pengguna, bukan klaim DRM anti-crack.
