## Aturan utama

Jangan membagikan:
- password/NIM;
- OTP;
- cookie/session token;
- activation/pairing secret;
- API key;
- file backup pribadi;
- materi/PDF yang tidak boleh didistribusikan.

Jangan menawarkan:
- penghapusan watermark;
- bypass/stealth terhadap blokir;
- jual-beli credential;
- spam, promosi ilegal, atau flood.

Community gate bertujuan membangun jalur komunikasi dengan pengguna, bukan klaim DRM anti-crack.
