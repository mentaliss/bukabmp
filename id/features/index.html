Fitur BMP Terbuka v1.2.0

Searchable PDF

OCR membuat teks pada PDF hasil dapat dicari.

Local-first processing

OCR, penyusunan PDF, cache, dan export utama berjalan di perangkat.

Resume & reuse data lokal

Modul yang sudah selesai dapat dipakai kembali untuk resume, export ulang, dan PDF gabungan tanpa mengulang OCR dari awal.

PDF gabungan

Buat PDF gabungan dari range yang lengkap. Jika ada modul yang hilang di tengah range, BMP Terbuka tidak berpura-pura membuat hasil lengkap.

Pengelolaan penyimpanan lokal

Kamu dapat melihat penggunaan penyimpanan lokal, mengelola data per BMP, export/reuse material yang tersimpan, menghapus data BMP tertentu, atau menghapus seluruh data lokal saat memang diperlukan.

Backup & Restore

Backup membantu menyimpan data lokal BMP Terbuka untuk pemulihan pribadi.

Restore memakai MERGE: data dari backup dipulihkan, item lokal yang cocok diperbarui dari backup, dan data lokal lain yang tidak terkait tidak otomatis dihapus.

Restore Edge Android

Di Edge Android, restore berjalan melalui tab restore khusus agar file picker Android dapat dibuka dengan benar. Desktop tetap memilih file restore dari popup.

Quiz Telegram

Untuk modul yang sudah diproses dan memiliki source Quiz lokal:

pilih modul → Mulai Quiz Telegram → lanjutkan di Telegram.

PDF mentah dan gambar halaman tidak dikirim untuk pembuatan Quiz. Source Quiz berasal dari teks yang diekstrak dan disanitasi secara lokal.

Safe stop

Saat sumber menolak akses, meminta login ulang, atau memberi kondisi yang tidak aman untuk dilanjutkan, BMP Terbuka berhenti tanpa blind retry.

Community + Supporter

Komunitas adalah ruang ngobrol dan aktivitas bersama. Supporter bersifat opsional dan tidak mengubah boundary privasi materi.
