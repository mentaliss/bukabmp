Code of Conduct

Jaga komunitas tetap berguna, aman, dan saling menghormati.

Tidak diperbolehkan:

  • membagikan password, cookie, session token, atau akun;
  • jual-beli credential;
  • mengunggah/menjual materi berhak cipta tanpa hak;
  • meminta atau menawarkan penghapusan watermark;
  • pelecehan, doxxing, spam, atau malware.

Diskusi teknis tentang keamanan diperbolehkan bila berorientasi pada pemahaman, perbaikan, dan responsible disclosure.
