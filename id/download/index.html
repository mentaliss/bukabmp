Download BMP Terbuka

Halaman ini adalah tujuan utama untuk download dan update BMP Terbuka.

Google Chrome — Desktop

Versi terbaru: v1.3.0

GitHub ZIP - current stable v1.3.0

Gunakan asset resmi:

BMP-Terbuka-v1.3.0-github.zip

Jangan gunakan asset otomatis Source code (zip) atau Source code (tar.gz) sebagai package extension.

Untuk update instalasi manual Chrome, download dan extract package baru, lalu ganti/overwrite isi folder yang sebelumnya dipilih saat Load unpacked. Setelah file versi baru sudah berada di folder yang sama, buka chrome://extensions dan tekan Reload. Reload sendiri tidak mengunduh update. Jangan uninstall, Remove, pindah ke folder baru, atau menghapus storage hanya untuk update normal.

Panduan lengkap: Instalasi & Update.

Chrome Web Store

Chrome Web Store belum tersedia untuk publik (Coming soon). Ketika tersedia nanti, instalasi Store akan mengikuti mekanisme update otomatis seperti extension Store desktop lain. Update Store bisa terlambat; pengguna desktop dapat membuka halaman Ekstensi dan memakai tombol Update jika tersedia. Developer mode mungkin perlu diaktifkan sementara agar tombol tersebut muncul.

Microsoft Edge — Desktop

Jalur resmi tetap Microsoft Edge Add-ons.

Microsoft Edge Add-ons

Microsoft Edge Add-ons masih menyediakan v1.2.0. Paket GitHub di atas sudah v1.3.0 dan versi Store menyusul setelah listing diperbarui. Instalasi dan update Edge Desktop mengikuti mekanisme Store normal.

Update Store biasanya terpasang otomatis, tetapi tidak selalu masuk secara instan setelah package baru dipublikasikan. Kalau ingin mengecek lebih cepat di desktop, buka edge://extensions lalu gunakan tombol Update jika tersedia. Developer mode mungkin perlu diaktifkan sementara. Jangan uninstall/reinstall atau menghapus data lokal hanya untuk update Store normal.

Microsoft Edge — Android

Gunakan Microsoft Edge Stable + Microsoft Edge Add-ons.

Microsoft Edge Add-ons

Edge Canary hanya fallback/testing.

Untuk update di Edge Android, jalur yang paling aman adalah menunggu automatic Store update. Update dapat terlambat dan Edge Android tidak menyediakan tombol Update desktop yang sama praktisnya.

Kalau memilih reinstall agar mendapat build terbaru lebih cepat, WAJIB buat Backup BMP Terbuka terlebih dahulu bila ingin mempertahankan data lokal. Menghapus/reinstall extension dapat menghapus cache/resume/Quiz source lokal extension. PDF yang sudah tersimpan di folder Downloads/perangkat tetap aman karena berada di luar storage extension. Setelah reinstall, lakukan aktivasi lagi bila diminta lalu Restore backup; Restore tetap memakai MERGE.

Untuk v1.2.0, fitur Restore di Android memakai tab restore khusus BMP Terbuka. Detail ada di Instalasi & Update dan PDF, Backup, Restore & Penyimpanan.

Microsoft Edge v1.2.0

v1.2.0 sudah live melalui listing resmi Microsoft Edge Add-ons untuk Desktop dan Android. Gunakan listing Store resmi; jangan memasang CRX diagnostic/audit sebagai jalan pintas.
