# Trademark & Brand Use

Source code yang dipublikasikan di repository ini menggunakan **GPL-3.0**. Lisensi source code tersebut tidak otomatis memberikan hak untuk menyatakan fork, service, atau distribution lain sebagai produk resmi BMP Terbuka.

Nama **BMP Terbuka**, logo, visual identity, dan representasi sebagai official BMP Terbuka tetap terpisah dari hak atas source code.

Kamu boleh menyebut BMP Terbuka secara faktual, menjelaskan bahwa software kamu berbasis/fork dari source BMP Terbuka, dan menautkan repository resmi.

Jangan mengklaim fork/build tidak resmi sebagai release resmi, memakai nama/logo dengan cara yang membingungkan soal afiliasi/endorsement, atau menyamar sebagai official support/store listing/service.

Fork yang dimodifikasi sebaiknya menggunakan branding yang jelas berbeda, terutama bila behavior privacy/security/community gate telah diubah.

Private backend, infrastructure, secret, dan production service tidak menjadi open-source hanya karena extension publik menggunakan GPL-3.0.
