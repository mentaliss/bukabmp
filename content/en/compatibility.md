# Compatibility

BMP Terbuka currently contains an adapter for the supported reader at:

https://pustaka.ut.ac.id/reader/

Listing a compatible URL does not imply affiliation, endorsement, or official support from the service owner.

The adapter is intended to use the user's normal authenticated browser session, request resources available to that session, preserve watermarks, stop on denied access, and process OCR/PDF locally.

It is not intended to add stealth techniques, credential theft, token forgery, IP rotation, or blind retries.
