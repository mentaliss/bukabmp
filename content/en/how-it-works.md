# How It Works

1. Install BMP Terbuka through a supported distribution path.
2. Complete community activation.
3. Sign in to the reader through its normal mechanism.
4. Select the material code and module range.
5. The extension requests pages available to your authorized browser session.
6. OCR and PDF creation run locally.
7. Module PDFs are cached locally and can be exported.
8. Later runs can resume from modules already stored.

BMP Terbuka does not grant new access rights and is not designed to bypass source access controls.
