# PDF, Backup, Restore & Storage

BMP Terbuka stores selected results locally so work can continue without unnecessary OCR repetition.

## Local Storage

Local data is used for resume, completed-module reuse, re-export, combined PDFs, and other features that require locally stored module data.

Files in Downloads are **exported copies**. Deleting a Downloads copy does not automatically remove data still stored by the extension.

## Storage Manager

In v1.2.0 you can:

- view local storage usage;
- see available BMP data;
- reuse/export supported data;
- remove data for one BMP;
- remove all local data when intentionally requested.

Create a backup first when you still need data that would be removed.

## PDF per Module & Re-export

A completed module can be exported again without OCR as long as its local data still exists.

## Combined PDF

A target range must be complete. If M5 is missing from M3–M6, finish M5 first before building the combined PDF.

## Resume

If M1–M4 are already complete and stored, rerunning M1–M9 can reuse M1–M4 and continue with missing modules.

## Backup

Backup stores BMP Terbuka local data for **personal recovery**.

The backup file may contain local study/material data. Keep it private and do not share it casually.

## Restore = MERGE

Restore is **not** “replace everything” and is not a full local database reset.

- backup data is restored;
- matching local items may be updated by backup contents;
- unrelated local data is not automatically erased.

## Restore on Desktop

Choose **Restore backup** from the popup and select the file through the desktop file picker.

## Restore on Edge Android

On Edge Android:

**Restore backup → BMP Terbuka restore tab → select file → restore runs in that tab.**

Keep the tab open until restore finishes. Closing the tab while it is running stops the process.

## Moving Browser or Device

Storage does not automatically move between Chrome and Edge, devices, browser profiles, or extension installations with a different identity.

Use Backup when you need to preserve local data before a major change.
