## Activation

A normal community activation token has a limited lifetime with a base period of about **14 days**.

v1.1.0 uses the newer token scheme and supports refresh when eligible. If refresh is unavailable, the extension may ask for re-verification.

Expired activation does not require reinstalling the extension.

## Minimum Version

Minimum-version policy can change through runtime policy.

If a version is no longer supported for starting new work or creating new activation, the extension will show an update notice.

Do not infer the current minimum version from an old release number; follow the extension notice and current runtime status.
