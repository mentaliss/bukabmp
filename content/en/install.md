# Installation & Updates

This page explains how to install and update BMP Terbuka based on your device and browser.

The installation path is not the same for every browser. For current distribution status, always check [Status & Version](../status).

## Choose Your Device and Browser

Current primary paths:

- **Android:** Microsoft Edge Stable + Microsoft Edge Add-ons.
- **Desktop Edge:** Microsoft Edge Add-ons.
- **Desktop Chrome:** manual installation from the official release ZIP.
- **Firefox:** not officially supported.
- **Chrome Android:** not an official installation target.

The current stable BMP Terbuka release is **v1.1.0**.

## Android — Microsoft Edge Stable

### What You Need

- an Android device;
- the latest Microsoft Edge Stable available for your device;
- Telegram for activation;
- normal access to the reader.

### How to Install

1. Install or update **Microsoft Edge Stable**.
2. Open Microsoft Edge.
3. Open the official BMP Terbuka listing in Microsoft Edge Add-ons.
4. Choose the option to install the extension.
5. Confirm the installation if Edge asks.
6. Open the extension list in Edge and make sure BMP Terbuka is installed.
7. Open BMP Terbuka and continue to activation.

Official Edge Add-ons listing:

https://microsoftedge.microsoft.com/addons/detail/mkgmigiagipmfdlppehhmckfokmpnmlm

### After Installation

Do not look for a BMP Code in Telegram. Activation starts from the extension popup.

Open [Activation & Verification](activation) for the next step.

### About Edge Canary

Edge Canary was used as an Android path in older versions and may still be useful for fallback/testing in specific cases.

For normal use now, use **Microsoft Edge Stable**.

## Desktop — Microsoft Edge

### How to Install

1. Open Microsoft Edge.
2. Open the BMP Terbuka listing in Microsoft Edge Add-ons.
3. Install the extension through Edge's normal extension flow.
4. Make sure BMP Terbuka appears in the extension list.
5. Pin it to the toolbar if you want faster access.
6. Open the popup and complete activation.

Official listing:

https://microsoftedge.microsoft.com/addons/detail/mkgmigiagipmfdlppehhmckfokmpnmlm

### Updating on Edge

Installs from Edge Add-ons follow the browser/store update mechanism.

If a new BMP Terbuka release exists but has not appeared on your device yet, check [Status & Version](../status). Store review and propagation can differ from the GitHub release timeline.

## Desktop — Google Chrome

Chrome Web Store is not an active BMP Terbuka distribution path yet. Chrome desktop users currently install BMP Terbuka manually from the official release ZIP.

### 1. Download the Release ZIP

Open GitHub Releases:

https://github.com/mentaliss/bukabmp/releases/latest

Download the release asset named like:

`BMP-Terbuka-v1.1.0.zip`

Do not download **Source code (zip)** or **Source code (tar.gz)**. Those are automatically generated by GitHub and are not the user extension package.

### 2. Extract the ZIP

Extract the ZIP into a folder you will keep.

Do not try to run the extension directly from the ZIP file.

Make sure the folder you plan to load contains `manifest.json`.

### 3. Open Chrome Extensions

Enter this in the address bar:

`chrome://extensions`

### 4. Enable Developer Mode

Turn on **Developer mode** on the Extensions page.

### 5. Choose Load Unpacked

Select **Load unpacked**, then choose the extracted folder containing `manifest.json`.

If Chrome rejects the folder, you probably selected the wrong folder level. Open the correct extracted folder and confirm that `manifest.json` is visible inside it.

### 6. Confirm BMP Terbuka Is Active

After loading:

- BMP Terbuka appears in the extension list;
- the extension is enabled;
- you can pin its icon to the toolbar.

Then continue to [Activation & Verification](activation).

## Updating a Manual Chrome Installation

For manual installs:

1. open [GitHub Releases](https://github.com/mentaliss/bukabmp/releases/latest);
2. download the newest official release ZIP;
3. extract the new package;
4. replace/update the folder used by the extension;
5. open `chrome://extensions`;
6. press **Reload** on BMP Terbuka;
7. open the popup and check the version.

An in-place update with the same extension identity usually preserves tokens, drafts, and local storage.

A new installation with a different identity can be treated by the browser as a different extension. Do not uninstall the previous version or clear data just to perform a normal update.

## Other Chromium Browsers

BMP Terbuka does not treat every Chromium browser as an officially supported target.

If a browser supports Manifest V3 extensions and **Load unpacked**, the manual package may technically load, but primary testing and documentation focus on Google Chrome and Microsoft Edge.

If you use another browser and run into a problem, include the browser name and version when requesting support.

## Firefox

Firefox is not currently an officially supported BMP Terbuka browser.

Use Google Chrome or Microsoft Edge on desktop. Use Microsoft Edge Stable on Android.

## Moving Browsers or Reinstalling

BMP processing results are stored in extension-local storage.

This means:

- PDFs already exported to Downloads remain normal files;
- resume/cache data should not be assumed to move automatically to another browser;
- uninstalling the extension or clearing browser data can remove local extension storage;
- if local storage is gone, required modules may need to be processed again.

If you only want to update, do not uninstall first.
