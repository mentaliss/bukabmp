# Lisensi Open Source

Source publik BMP Terbuka di repository ini menggunakan **GNU GPL-3.0**.

Teks lisensi lengkap tersedia pada file LICENSE di repository.

GPL-3.0 berlaku pada source yang dipublikasikan dan berada dalam scope repository ini. Lisensi tersebut tidak otomatis memberikan hak atas nama/logo/identitas resmi BMP Terbuka, private backend, production infrastructure, atau private signing material.

Lihat halaman Trademark untuk batas antara hak source code dan penggunaan brand.
