## Microsoft Edge — Desktop & Android

https://microsoftedge.microsoft.com/addons/detail/mkgmigiagipmfdlppehhmckfokmpnmlm

Aktivasi kedaluwarsa tidak mengharuskan install ulang.

Kebijakan minimum version berasal dari runtime policy. Jangan menebak minimum version dari nomor release di halaman ini. Ikuti pesan extension dan jalur update yang benar-benar tersedia.
