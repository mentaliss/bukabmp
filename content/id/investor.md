# Investor / Partnership

BMP Terbuka adalah utility browser extension untuk membuat materi yang sudah dapat diakses pengguna lebih nyaman dipelajari sebagai searchable PDF.

## Product

Masalah yang diselesaikan adalah friction pada workflow belajar: materi dapat diakses, tetapi pencarian teks, penyimpanan per modul, resume, dan export sering tidak nyaman.

Solusinya adalah extension local-first dengan OCR/PDF di perangkat, community/support layer, dan public open-source client.

## Traction

Public metrics hanya akan memakai definisi yang benar, misalnya observed installations, active installations pada periode tertentu, community members, dan release/download counts. Pseudonymous installation identities tidak boleh disebut sebagai verified human users.

## Distribution

- Microsoft Edge Add-ons untuk Edge Desktop dan Android setelah listing resmi terverifikasi;
- GitHub Releases untuk manual supported installation;
- community channels untuk update/support.

## Business model

Supporter, sponsorship, advertising, partnership, dan potential investment. Tidak ada fabricated rate, revenue, valuation, atau TAM.

## Technology and governance

Extension open-source; production backend/infrastructure private. Isi BMP/OCR/PDF local-first. Advertiser tidak mendapat akses ke user identity atau per-user private telemetry.
